"Built on" is a statement about origin. It does not say what happens when something goes wrong. The distance
test does: if everyone in between failed or colluded, what could the root still guarantee for you?

Five answers cover the ground, from the root itself to no tie at all. A system can be built on a root and
still be a long way from it.

This is not an argument against bridges or other ledgers. It is a way of saying plainly how much of the
root's trust reaches the person using them.

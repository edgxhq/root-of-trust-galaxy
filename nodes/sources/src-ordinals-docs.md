The handbook of the Ordinals project. On Runes: "Runes allow Bitcoin transactions to etch, mint, and transfer
Bitcoin-native digital commodities", and "Rune protocol messages, called runestones, are stored in Bitcoin
transaction outputs." Its introduction says ordinal theory "can be used without any changes to the Bitcoin
network".

A modular Cardano node in Rust from Input Output. Its README, read on 20 November 2026, still says the project
"is intended to be a full block-producing node on mainnet". Its overview lists a block-producing node as the
fourth of five deliverables. Input Output halted further development on 7 April 2026; the repository's last
tagged release is from that month. No source says it has made blocks on any public network.

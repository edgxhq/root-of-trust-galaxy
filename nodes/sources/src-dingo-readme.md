Dingo is Blink Labs' Cardano node in Go. Its README, read on 20 November 2026: "Dingo is under heavy active
development and is not yet ready for mainnet block production use. It should only be used on testnets
(preview, preprod, musashi, dijkstra) and devnets. Do not use Dingo on mainnet for block production with real
funds." Its operator guides cover stake pool operation, including setting up a pool on the Leios test network.
Its latest release on 19 November 2026 was v0.94.2 of 16 November. Read again on 24 November, the README's
warning was unchanged, while Intersect reported that Dingo had passed 100 mainnet blocks
([[src-intersect-weekly-update-138]]).

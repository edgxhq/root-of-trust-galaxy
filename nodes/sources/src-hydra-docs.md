The documentation of the Hydra Head protocol, version 2.4.2, read on 20 November 2026. "The Hydra Head
protocol is a layer 2 scaling solution for Cardano". "Many transactions and arrangements can occur within a
single Hydra head, with deposits, decommits, and final settlement recorded on the main chain." On safety: "An
honest party can use signed snapshots to contest an outdated close, provided it monitors Cardano within the
contestation period." Cardano's own documentation describes a head as "an off-chain mini ledger shared between
a small group of participants".

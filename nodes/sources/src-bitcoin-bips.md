Read on 19 November 2026 in the repository of Bitcoin improvement proposals: BIP-119, "CHECKTEMPLATEVERIFY",
status Draft; BIP-347, "OP_CAT in Tapscript", status Complete; BIP-348, "CHECKSIGFROMSTACK", status Draft.
Each is listed as "Consensus (soft fork)". A status describes the document, not the network: none of the three
is active on Bitcoin's main network. The link is to BIP-347; the others are beside it in the same repository.

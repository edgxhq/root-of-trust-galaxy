A public index that measures decentralisation layer by layer (consensus, tokenomics, software, network,
geography) and publishes its data and code. It gives each layer a score and a Nakamoto coefficient and publishes
no overall ranking. Four chains have scores on all five layers: Bitcoin, Cardano, Ethereum and Litecoin. Limits to
keep in view: it is part-funded by Input Output; its software layer measures how concentrated code contributions
are, not how many node implementations exist; governance is not scored; and its Ethereum consensus data was from
February 2025 when read. The score table used here was last modified on 20 August 2026.

A proposal in Midnight's own improvement process, status Proposed when read on 18 and 19 November 2026. The
link is to the file as it stood at commit 0de284e.

Its abstract: "This proposal defines how Midnight block production rewards are paid in NIGHT on Cardano." Each
epoch the amount earned by a stake pool is split "between the pool's operator and its delegators in the same
proportions as Cardano staking rewards".

A proposal open for comment is not an adopted decision.

A draft problem statement in Midnight's own improvement process, read on 18 and 19 November 2026. The link is
to the file as it stood at commit 0de284e.

It records that every Midnight node needs a Cardano node, db-sync and PostgreSQL. From its abstract: "The
Cardano dependency is therefore the largest single item in a Midnight node's operating envelope". It asks for
a lighter way to observe Cardano, not for removing the dependency.

A draft open for comment is not an adopted decision.

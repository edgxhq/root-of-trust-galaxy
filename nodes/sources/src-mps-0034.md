A problem statement in Midnight's own improvement process, status Proposed when read on 18 and 19 November
2026. The link is to the file as it stood at commit 0de284e.

- Vision: "This is also the first piece of network sovereignty. Today every path into Midnight block
  production and its rewards begins on Cardano. Native NIGHT staking gives Midnight one participation and
  security parameter that it defines and adjusts itself."

- Goals: "Participation should extend beyond the registered SPO set without displacing it."

- Success criteria: "The chain is able to operate in a blended stake mode, where ADA SPOs can have a weighted
  proportion of block production. The proportion needs to be configurable."

Success criteria also include: "The stakeable form of NIGHT is mNIGHT."

A problem statement open for comment is not an adopted decision.

The list of keys whose signatures are accepted on merges to Bitcoin Core. It held five fingerprints on 19
November 2026. The project's contributing guide says "there are repository maintainers who are responsible for
merging pull requests, the release cycle, and moderation." The file governs the repository, not the chain.

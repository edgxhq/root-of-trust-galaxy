Bitcoin's developer documentation. "The script language is a Forth-like stack-based language deliberately
designed to be stateless and not Turing complete." It gives the reason: "Turing-incompleteness (specifically,
a lack of loops or gotos) makes the script language less flexible and more predictable, greatly simplifying
the security model."

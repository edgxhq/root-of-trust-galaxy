Every domain name resolves from a single root. The body that coordinates it set out why in 2001: a globally
unique public name space must be "derived from a single, globally unique DNS root".

It is the clearest institutional precedent for one root. A name has to mean the same thing to everyone, so
there can be only one place that says what it means. The same reasoning applies to a fact about who owns what.

The DNS root has a steward. A public ledger is an attempt at a single root without one.

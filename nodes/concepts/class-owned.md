The roots of trust that came before public ledgers: the root of the internet's naming system, the certificate
authorities behind the padlock in a browser, the key built into a chip, a fingerprint printed in a newspaper.

Each does one thing, and each has an owner or a small set of them. A public ledger is an attempt at a root
without one. See [[root-of-trust]].

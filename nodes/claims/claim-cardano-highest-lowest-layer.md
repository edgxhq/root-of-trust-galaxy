The index's published scores, out of 100, read on 19 November 2026 (data last modified 20 August 2026):

| Layer | Bitcoin | Cardano | Ethereum | Litecoin |
|---|---|---|---|---|
| Consensus | 82.84 | 99.37 | 66.13 | 79.78 |
| Tokenomics | 95.41 | 83.59 | 72.10 | 91.03 |
| Software | 91.31 | 92.88 | 97.03 | 85.00 |
| Network | 96.68 | 95.32 | 99.28 | 92.50 |
| Geography | 81.45 | 85.52 | 82.58 | 89.58 |
| Lowest | 81.45 | 83.59 | 66.13 | 79.78 |
| Average | 89.54 | 91.34 | 83.42 | 87.58 |

The last two rows are this research's arithmetic. The index publishes no overall ranking.

**Limits.** Only these four chains have all five layers; Solana and the XRP Ledger are absent. The software
layer measures how concentrated code contributions are, not how many node implementations exist. Governance
is not scored. The index is part-funded by Input Output. So this claim does not show that Cardano is the most
decentralised network; it shows that it leads on the layers this index measures.

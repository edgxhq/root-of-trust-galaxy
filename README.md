# Root of Trust Galaxy: the research graph

The research graph behind the [Root of Trust Galaxy](https://rootoftrust.edgx.tech), a map of the roots of trust
people rely on: who owns them, what they can do, and what it takes to keep one decentralised. One markdown file
per node. The format is in
[SCHEMA.md](SCHEMA.md), and [INDEX.md](INDEX.md) lists every node.

- Every measurement names its source, its date and how far it has been checked.
- **Suggest a change** with [the form](https://github.com/edgxhq/root-of-trust-galaxy/issues/new?template=suggest-a-change.yml). No fork needed. How a
  suggestion is decided is in [CONTRIBUTING.md](CONTRIBUTING.md). A link nobody has counted yet is an open
  invitation.
- Shared under CC BY 4.0 ([LICENSE](LICENSE)): reuse it freely, with credit to the Root of Trust Galaxy and a link
  to this repository.
- This is a filtered snapshot of a private working repository, with drafts and internal notes left out. Each
  update replaces the history with one snapshot.
